# Demo Django + Tailwind + Docker 🐳

Este projeto é uma demonstração prática de uma aplicação web de página única (Single Page) construída com **Django 5.1**, estilizada com **Tailwind CSS** (via CDN) e totalmente containerizada utilizando **Docker** e **Docker Compose**.

O projeto faz parte das atividades práticas da disciplina de Programação Web.

---

## 🚀 Tecnologias Utilizadas

- **Python 3.12 & Django 5.1:** Framework backend robusto com sistema de templates e ORM nativo.
- **Tailwind CSS:** Framework utilitário de CSS para estilização rápida e moderna.
- **SQLite:** Banco de dados relacional leve e local.
- **Docker & Docker Compose:** Isolamento completo do ambiente de desenvolvimento, dispensando a necessidade de instalar o Python localmente.
